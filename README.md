# Autsors — учёт внешнего персонала РРС Тюмень

Веб-приложение администратора и управляющего, Telegram-бот для оперативной работы и отчётности сотрудников.

## Возможности

- Администратор управляет пользователями, правами и всеми филиалами. УМ работает в назначенных филиалах; сотрудник — через бота.
- Вход по email и PIN из 4–12 цифр, обязательная смена временного PIN, личный кабинет и аватарка.
- Сотрудники, дневные смены, отчёты, фактические часы и подтверждение управляющим.
- Одноразовый код привязки Telegram, меню по роли, уведомления и напоминания.
- График работы каждого филиала и история изменений.
- Excel: отдельный файл на филиал, отдельный лист на месяц, таблицы и графики; несколько филиалов — ZIP.

## Установка на сервер

Нужны Linux, Docker Engine, Docker Compose plugin, openssl и домен с доступными портами 80/443.

```bash
git clone https://github.com/maiklvas-bot/Autsors.git
cd Autsors
bash install.sh
```

Установщик запросит домен, email администратора, PIN и токен бота. Compose запускает приложение и Caddy с HTTPS; данные сохраняются в Docker-томе. Подробности: [INSTALL.md](INSTALL.md).

Установка создаёт новую базу. Рабочие данные размещённого сайта автоматически не переносятся. Один Telegram-бот может иметь только один webhook: установка с тем же токеном переключит его на новый домен.

## Разработка и проверки

Linux, Node.js 24 и npm. Версии зависимостей зафиксированы в package-lock.json.

```bash
npm ci
npm test
```

`npm test` собирает приложение и выполняет автоматические тесты. `npm run dev` запускает среду разработки. Самостоятельный production-сервер — `deploy/server.mjs`, используйте Docker-инструкцию для конфигурации и первого администратора.

В репозиторий входят исходники, миграции, тесты, начальный справочник филиалов и шаблон Excel. Рабочая база, секреты, фотографии пользователей и корпоративные исходные документы не публикуются.
