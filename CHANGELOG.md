# История изменений

## 2026-09-11 — 0.1.1

- Исправлен просмотр фотографий отчётов в веб-интерфейсе при общем MIME-типе Telegram.
- Ошибки загрузки фотографий теперь возвращают корректный статус и пишутся в журнал сервера.
- Выбор задач при назначении смены перенесён на inline-кнопки с действиями «Выбрать все», «Очистить» и «Готово».
- Ручной выбор задач принимает пробелы, запятые, диапазоны и команду «все».
- Дата смены принимается в форматах ДД.ММ.ГГГГ и ГГГГ-ММ-ДД; добавлены кнопки «Сегодня» и «Завтра».

## 2026-09-09 — первоначальная публикация на GitHub

- Учёт внешнего персонала, смены, отчёты и подтверждение фактических часов.
- Роли, ограничения по филиалам, PIN и личный кабинет.
- Telegram: одноразовая привязка, меню и приём webhook.
- Графики филиалов, история и Excel по месяцам и филиалам.
- Docker Compose, установщик с запросом домена, Caddy HTTPS и минутный планировщик.
- Руководства эксплуатации, безопасности и разработки.

История ранних разработок сохраняется в исходном репозитории Sites. GitHub содержит подготовленный снимок проекта, без рабочей базы и секретов.
