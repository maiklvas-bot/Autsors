# История изменений

## 2026-09-11 — 0.1.3

- Запрос на подтверждение часов теперь появляется только после планового окончания смены и получения итогового отчёта сотрудника.
- Ранний итоговый отчёт сохраняется, но не открывает подтверждение часов до конца смены.
- Telegram-раздел «На подтверждении» больше не показывает незавершённые смены.
- Веб-карточка смены также скрывает подтверждение часов до готовности смены к проверке.
- Сервер блокирует раннее подтверждение даже при ручном вызове старой кнопки/callback.
- Сценарий «Не вышел» сохранён и доступен только после планового окончания смены.

## 2026-09-11 — 0.1.2

- Исправлена доставка уведомления сотруднику при назначении смены через Telegram-бота; администратор теперь видит фактический результат доставки.
- Ошибка отправки одному получателю больше не блокирует уведомления другим; планировщик продолжает обработку после единичных ошибок.
- Добавлен повтор отправки при кратковременных сетевых ошибках и Telegram 429/5xx.
- Интерфейс бота переведён на возможности Telegram Bot API 10.3: цветные inline-кнопки для основных, успешных и опасных действий.
- Выбор задач теперь обновляется в одном сообщении вместо создания цепочки новых сообщений.

## 2026-09-11 — 0.1.1

- Исправлен просмотр фотографий отчётов в веб-интерфейсе при общем MIME-типе Telegram.
- Ошибки загрузки фотографий теперь возвращают корректный статус и пишутся в журнал сервера.
- Выбор задач при назначении смены перенесён на inline-кнопки с действиями «Выбрать все», «Очистить» и «Готово».
- Ручной выбор задач принимает пробелы, запятые, диапазоны и команду «все».
- Дата смены принимается в форматах ДД.ММ.ГГГГ и ГГГГ-ММ-ДД; добавлены кнопки «Сегодня» и «Завтра».

## 2026-09-09 — первоначальная публикация на GitHub

- Учёт внешнего персонала, смены, отчёты и подтверждение фактических часов.
- Роли, ограничения по филиалам, PIN и личный кабинет.
- Telegram: одноразовая привязка, меню и приём webhook.
- Графики филиалов, история и Excel по месяцам и филиалам.
- Docker Compose, установщик с запросом домена, Caddy HTTPS и минутный планировщик.
- Руководства эксплуатации, безопасности и разработки.

История ранних разработок сохраняется в исходном репозитории Sites. GitHub содержит подготовленный снимок проекта, без рабочей базы и секретов.
