# Проверка и ограничения на 09.09.2026

До публикации на GitHub прошли 38 автоматических проверок. Самостоятельный Node-сервер проверен с реальной SQLite: вход, сохранение сеанса после перезапуска, загрузка/чтение аватарки и отказ при подделке платформенной личности.

На размещённом сайте зафиксированы успешная регистрация Telegram webhook и шесть входящих запросов Telegram со статусом 200. Это подтверждает доставку запросов; не заменяет проверку всех пользовательских диалогов реальными участниками.

## Оставшиеся ограничения

- В среде разработки нет Docker Engine: сборка образа, запуск Compose и HTTPS на пользовательском домене здесь не проверены.
- Постоянный планировщик напоминаний на Sites не запущен. В самостоятельном Node-сервере предусмотрен минутный планировщик.
- Начальный справочник содержит 24 филиала из утверждённого владельцем списка от 09.09.2026.
- Самостоятельная установка создаёт новую базу, автоматического переноса данных Sites нет.
- Полная проверка всех экранов в браузере и независимый аудит безопасности не проводились.

Для проверки установки и резервного копирования используйте INSTALL.md. CI выполняет автоматические тесты и сборку Docker; результат конкретного запуска смотрите во вкладке Actions.
